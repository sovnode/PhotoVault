# PhotoVault tag groups

# Which group each tag is listed under when you set up a smart album's tag
# filter. PhotoVault reads this file each time it opens, so changing it never
# needs a new version of the app. Edit it in any text editor.
#
#   [Group name]   starts a group. Groups appear in the filter in this order,
#                  each as a list you can open and close.
#   a tag          one per line, listed under the group above it.
#   # ...          a comment. Blank lines are ignored.
#
# Write tags the way PhotoVault shows them, without a "jt:" or other prefix.
# Capitals don't matter, and a space and an underscore count as the same, so
# "blonde hair" also matches JoyTag's "blonde_hair". A tag goes in the group its
# name is listed under whichever tool wrote it, so your own keywords can be
# grouped here too. A tag listed in two groups shows in both. A tag listed
# nowhere shows under "Other".
#
# Groups are PhotoVault's own, and so are JoyTag's tags: both are kept in
# PhotoVault's catalog, and nothing is ever written into your photos.
#
# R18 holds nude and explicit content only: nudity, sex, sexual fluids and
# toys, bondage, and graphic gore. JoyTag misreads some photos, so innocent
# photos can land in R18 too. Anime and games holds character, series, game
# and artist names; Fantasy and sci-fi holds magic, monsters, robots, and
# non-human features such as animal ears and wings.
#
